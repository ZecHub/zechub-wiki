# Getting Started with ZecHub

Welcome to ZecHub, the community-driven hub for all things Zcash! Whether you are here to learn about privacy tech, explore ecosystem tools, or contribute to the wiki, this guide will help you find your footing.

## 1. Explore Zcash Fundamentals
If you are new to privacy-preserving cryptocurrencies, start by understanding the core concepts:
* **Decentralized Currency:** Learn how Zcash provides peer-to-peer digital cash with optional financial privacy.
* **Shielded Pools:** Discover how zero-knowledge proofs (zk-SNARKs) keep transaction details confidential[cite: 5].

## 2. Set Up Your Wallet
To interact with the Zcash network securely, you'll want to choose a wallet that supports shielded addresses (Sapling and Orchard):
* Choose between mobile wallets for on-the-go transactions or desktop/hardware setups for long-term storage.
* Always back up your seed phrase securely offline.

## 3. How to Contribute
ZecHub thrives on community contributions. You can help expand and maintain our documentation:
* Check our open GitHub repository and issues list.
* Follow our Markdown and YAML frontmatter standards when submitting pull requests.
* Join community discussions to share ideas and collaborate with other contributors.
