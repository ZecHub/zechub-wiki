# Zcash Mining Basics

Zcash secures its network and validates transactions through a proof-of-work consensus mechanism designed to be ASIC-resistant and secure.

## The Equihash Algorithm
Zcash utilizes Equihash, a memory-oriented proof-of-work algorithm. This means the mining process depends heavily on RAM performance rather than raw processing power alone, helping decentralize participation.

## Network Security
Miners bundle transactions into blocks, securing the blockchain ledger while earning block rewards. The protocol's halving schedule mirrors Bitcoin's, controlling issuance over time.
